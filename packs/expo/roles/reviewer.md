# expo · reviewer
Applies when: `expo` or `react-native` in package.json, or `app.config.*` / `eas.json` present
Read order: expo-secure-store-tokens, expo-public-env, expo-deeplink-validate, expo-oauth-pkce, expo-webview-origin, expo-cleartext-off, expo-ota-no-native, expo-list-stable-rows, expo-router-typed-routes, expo-permission-lazy-with-denial

## Blocker vs should-fix
- Blocker: a native dependency, config plugin or permission added without a runtime version change (or fingerprint policy) when the project ships with EAS Update.
- Blocker: a deep-link or WebView message handler that mutates state without user confirmation.
- Should-fix: index keys or `ScrollView` + `map` on a list fed by an API; hand-built route strings in a typed-routes project; permission prompts on launch.
- Should-fix: platform branching scattered through a component when the codebase uses `Platform.select` or platform files.

## Obstacles to report
- Files under `ios/` or `android/` edited in a project whose native folders are generated by prebuild: the edit is lost on the next `npx expo prebuild --clean`.
